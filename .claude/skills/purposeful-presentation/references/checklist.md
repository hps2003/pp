# 交付前檢查表

## 整份

- [ ] Brief 已寫明：目的、受眾、受眾的專業／立場／時間、決策者、內部或外部情境
- [ ] 第一頁破題：議題、為什麼現在、希望得到什麼結果
- [ ] 每換一個主題都有轉折頁
- [ ] 上下頁有邏輯關係；拿掉任何一頁，故事會斷
- [ ] 產品／提案類依序涵蓋：使用者需求 → 產品／方案 → 創新性 → 獨特性 → 成果數據 → 下一步（依受眾可刪減）
- [ ] 最後一頁告訴決策者要做什麼
- [ ] 動畫只有淡入／淡出，且只用於逐步推理
- [ ] 字體統一（微軟正黑體系列，或品牌字＋微軟正黑體後備）

## 每頁

- [ ] 只講一件事
- [ ] 標題是結論或觀點，不是主題名稱
- [ ] 內文 ≤ 20 字（不含標題與圖表標籤）
- [ ] 主次分明：一眼看出主訊息，次要資訊在字級、顏色、位置上讓位
- [ ] 最小字 ≥ 16 pt、標題 ≥ 26 pt、重點 ≥ 40 pt
- [ ] 沒有淺底白字、深底黑字、相近飽和度相鄰；文字對比 ≥ 4.5:1
- [ ] 顏色區分靠明度，不只靠色相；數值直接標註
- [ ] 數據有單位、期間、來源，且全部來自素材（沒有杜撰）
- [ ] 圖表類型符合用途（占比＝圓餅、比較＝長條、趨勢＝折線、多屬性＝表格）
- [ ] 框線最多 3 個、不套框，主區與次區線條有別
- [ ] 備註只有提示關鍵詞，不是逐字稿

## 提醒使用者

- [ ] 正式簡報前到現場投影，從最遠與最偏的座位檢查
- [ ] 列出「待補數據」與刻意保留的例外
